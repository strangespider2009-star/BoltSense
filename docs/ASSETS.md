# Model assets

No external proprietary, scraped, or unlicensed 3D assets are distributed in this repository.

The current machine geometry is generated from basic Three.js meshes and is explicitly identified throughout the UI as a **procedural demonstration**, not detailed engineering CAD.

To add real assets, obtain permitted/licensed GLB or GLTF files, preserve their attributions, establish a stable mapping between mesh names and BoltSense component IDs, and verify interaction performance on mobile devices.
